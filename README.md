# SpotPins

Map and minimap pins for farming spots (Shellfish Traps, Elemental Water patches, Deviate Fish pools, Horde flight paths, mining nodes) plus your own.

An addon for **World of Warcraft: Forever** (interface 16001), made for personal use and shared as-is.

## Install

- **WowUp:** Add Addon → Install from URL → paste this repository's URL. Updates come with each new release.
- **Manual:** download `SpotPins-<version>.zip` from the Releases page and unzip it so the `SpotPins` folder sits in `_forever_\Interface\AddOns\`.

Type `/reload` in game after updating.
